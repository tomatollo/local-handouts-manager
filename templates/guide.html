⚙️ {{ 'Installazione e Aggiornamento' | t }}

{{ 'Questa è una versione sintetica. La guida completa, con tutti i dettagli per Windows, macOS e Linux, si trova nel file INSTALL.md nella cartella del progetto.' | t }}

{{ 'Cosa serve' | t }}

  • {{ 'Python 3.9 o più recente.' | t }} {{ 'Su Windows, durante l\'installazione ricorda di spuntare "Add python.exe to PATH".' | t }}
  • {{ 'Git' | t }} {{ '(consigliato, rende gli aggiornamenti immediati) oppure il download del codice come file ZIP.' | t }}

{{ 'Prima installazione (una volta sola)' | t }}

  1. {{ 'Scarica il codice:' | t }} {{ 'con Git, clona il repository ed entra nella cartella del progetto; oppure estrai lo ZIP e aprivi un terminale.' | t }}
  2. {{ 'Crea l\'ambiente virtuale e installa le dipendenze:' | t }} {{ 'crea una cartella .venv, attivala e lancia l\'installazione dei pacchetti richiesti. Il launcher cerca .venv in automatico, quindi vale la pena crearla.' | t }}

{{ 'Windows (PowerShell):' | t }}

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

{{ 'macOS / Linux:' | t }}

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

{{ 'Avviare il programma' | t }}

  • {{ 'Con il launcher (consigliato):' | t }} {{ 'su Windows fai doppio clic su start_launcher.bat; su macOS/Linux lancia python launcher.py con la .venv attiva. Poi premi "Start server" e leggi l\'indirizzo di rete da dare ai giocatori.' | t }}
  • {{ 'Da terminale:' | t }} {{ 'con la .venv attiva, lancia python app.py e apri http://localhost:8000. Comodo per le prove veloci.' | t }}

🔄 {{ 'Come aggiornare il software' | t }}

{{ 'I dati della tua campagna vivono nella cartella data/ e i file caricati in static/uploads/ e static/maps/. Questi sono esclusi dal controllo di versione, quindi un normale aggiornamento non li tocca mai.' | t }}

{{ 'Se hai usato Git:' | t }}

git pull
# poi, con la .venv attiva, se le dipendenze sono cambiate:
pip install -r requirements.txt
