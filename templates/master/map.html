{# Master's interactive map: upload + calibratable hex grid (offset + hex size) + fog-of-war (reveal/re-hide) + draggable marker, all STAGED behind an explicit "Reveal to players" confirm. Two layers of truth (see storage.py): * confirmed -> what players see. Shown here as fully-transparent hexes. * pending -> the Master's draft. Edits land here; players never see it until Confirm. Draft-only reveals are drawn semi-clear with a dashed gold edge; a draft-hidden hex that is still live for players is drawn with a dashed red edge. Grid placement is by CALIBRATION, not by stretching to the image edges: * hex_size = one hex's width as PERCENT of the image width; * offset_x/offset_y = where the first hex's centre sits, PERCENT of image. This lets the overlay be nudged onto a map that already has hexes printed on it. Everything is percent-based so it survives a resolution change. The pan/zoom fix vs the earlier version: hexes no longer block Panzoom. Instead a click is distinguished from a drag by how far the pointer moved, so you can both click single hexes and drag the whole map. #} {{ 'Interactive Map' | t }} {% include '_head.html' %}
